## Detailed Results

### KILN-012: Session stats + per-tick status event (gate)
**Status:** completed · **Commit:** 4b3f737 · **GitHub:** #12
**What:** `kiln/stats.py` `SessionStats` (turns, tokens total + by branch, latency
averages); extended the `Output` seam with `status(snapshot)`. `run()` times each
turn, folds it into `SessionStats`, and emits a `status` snapshot **every tick** —
`{status, model, branch, needs, thresholds, hottest, cooldowns, stats}`.
`ConsoleOutput.status` is a no-op; `TuiOutput` emits a `status` event to the bus.
**Validation:** [x] pytest 88 · [x] ruff · [x] dry-run unchanged (status no-op on console)
