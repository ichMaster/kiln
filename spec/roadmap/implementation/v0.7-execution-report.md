## Model / cost note

Usage is captured off the brain seam (SDK `msg.usage` / CLI `data.usage` + `total_cost_usd`); cost
is the CLI's actual where present, else estimated from `cost.py`. All tests run on fixtures + a mock
brain — the cost math and report aggregation are pure, so **zero paid calls**. `$` figures are
estimates (cache read 10% input; cache write 1.25× @ 5m / 2× @ 1h), not a billing source of truth.
