# v0.8 — GitHub Issues

Issues for phase **v0.8 — World & temporal awareness** (version **v0 — Prototype & TUI**), derived
from the per-phase Tasks in [ROADMAP.md](../../ROADMAP.md) (§0.8) and the contracts in
[ARCHITECTURE.md](../../ARCHITECTURE.md) (§Contracts — Canon/system-prompt + Store, §Memory and
transcripts). This file is scoped to a single phase; IDs continue from the previous phase
(KILN-030 → **KILN-031…034**).

v0.8 gives Agnika a sense of **time, place, and conversation tempo**: a `## Зараз` world-now section
(weekday/date, time-of-day, season, location, a rhythm cue) and a `## Останні повідомлення` section
(the last N turns each precisely timestamped) injected into the system prompt of every branch.
Turns gain an `at` stamp, and the world block is composed **per turn** so the clock and the timeline
stay live. All computed **locally** — no external calls; weather/calendar/news are a later
tool-backed layer.

## v0.8 — World & temporal awareness

### KILN-031 — World-now builder + location config (`kiln/world.py`)

**Description:**
A pure, deterministic formatter for the current moment — weekday, date, time, time-of-day, season,
location — as a short Ukrainian paragraph with a rhythm cue. New module `kiln/world.py`; new config
knobs. No external calls; takes an injected clock so it's fully testable.

**What needs to be done:**
- `world_now(now, location="") -> str` in `kiln/world.py`: a short Ukrainian paragraph — weekday +
  date, time + **time-of-day** (ранок / день / вечір / ніч by hour band), **season** (by month),
  location (only when given), and a one-line **rhythm cue** (tone shifts by time of day). Pure:
  `now` is a `datetime` passed in (never `datetime.now()` inside the function).
- Config: `USER_LOCATION` (`.env`-overridable, default empty) and optional `TIMEZONE` (else the
  local clock). Ukrainian weekday/month names live in `world.py`.
- Keep it persona-layer Ukrainian (the system prompt), per the language convention.

**Dependencies:** None (gate).

**Expected result:**
`world_now(fixed_datetime, "Львів")` returns a compact Ukrainian "now" paragraph with a rhythm cue.

**Acceptance criteria:**
- [ ] **Unit test:** `world_now` formats correctly across fixture times — each time-of-day band
  (morning/day/evening/night) and each season boundary; with and without a `location`; the rhythm
  cue is present. Pure (a fixed `now`), **mock brain / no paid call**.
- [ ] `USER_LOCATION` / `TIMEZONE` are read from config (`.env`-overridable).
- [ ] Ties to the phase DoD: a `## Зараз` paragraph (date/weekday/time-of-day/season + location) is
  produced deterministically from an injected clock.

### KILN-032 — Timestamp each turn (`{role, text, at}`)

**Description:**
Give every conversation turn a precise timestamp so the recent-messages block (KILN-033) can show
when things were said. The history/store turn shape gains an `at` field — a small **seam change**.
Touches `history.py` (turn shape + helpers), `engine.py` (stamp on append), and the store
(`messages` persist `at`).

**What needs to be done:**
- The turn item becomes `{role, text, at}` where `at` is an ISO timestamp (seconds). Document/define
  it in `history.py`; `to_messages`/`to_transcript` keep reading only `role`/`text` (ignore `at`, so
  the brain seam is unchanged).
- `engine.respond()` stamps both the user turn and the bot turn with `at` on append. The clock source
  is injectable/monkeypatchable for deterministic tests.
- The store's `messages` now round-trip turns that carry `at` (no schema break — it's an extra key on
  each turn). Update ARCHITECTURE §Contracts (Store `messages` turn shape) + §Memory.

**Dependencies:** None (gate).

**Expected result:**
Every appended turn carries an `at` ISO timestamp; existing transcript/message helpers are unaffected.

**Acceptance criteria:**
- [ ] **Contract test:** the turn shape — appended turns are `{role, text, at}`; `to_messages` →
  `{role, content}` and `to_transcript` → text lines, both **ignoring** `at`; the store round-trips
  turns with `at`. Pinned in `spec/ARCHITECTURE.md`.
- [ ] **Unit/integration test:** a `run()` turn appends user + bot turns each with an `at` stamp
  (controlled clock) — **mock brain**, tmp paths, zero paid calls.
- [ ] Ties to the phase DoD: turns are stamped with `at`.

### KILN-033 — Recent timed-messages builder + `RECENT_MESSAGES`

**Description:**
Render the last N turns as a timestamped timeline — the `## Останні повідомлення` block — from the
turns' `at` stamps. Pure builder + a config knob. Touches `kiln/world.py` (or `history.py`) and
`config.py`.

**What needs to be done:**
- `recent_timed(history, n, now) -> str`: the last `n` turns, each as `[Сб 11:52] Користувач: …` /
  `[11:55] Ти: …` — the **date prefix shows only when the day changes** (from the previous line or
  from `now`); turns missing `at` degrade gracefully (time omitted). Returns the block body, or `""`
  when `n == 0` or there are no turns.
- Config: `RECENT_MESSAGES` (N, default `10`; `0` = off), `.env`-overridable.
- Ukrainian labels (Користувач / Ти), persona-layer.

**Dependencies:** KILN-032 (turns carry `at`).

**Expected result:**
`recent_timed(history, 10, now)` returns the last 10 turns as `[date? time] role: text` lines.

**Acceptance criteria:**
- [ ] **Unit test:** renders the last N turns with timestamps; the **date-change rule** (same day →
  time only; new day → date + time); `n == 0` / empty history → `""`; a turn without `at` is shown
  without a timestamp. Deterministic (fixture turns + fixed `now`), no paid call.
- [ ] `RECENT_MESSAGES` is read from config (`.env`-overridable).
- [ ] Ties to the phase DoD: a `## Останні повідомлення` block of the last `RECENT_MESSAGES` turns,
  each precisely timestamped.

### KILN-034 — World + messages → system prompt (per-turn)

**Description:**
Compose the `## Зараз` + `## Останні повідомлення` sections into the system prompt of every branch,
**rebuilt per turn** so the clock and the timeline stay live (the timed block is empty at session
start, so a once-at-start build won't do). Touches `memory.py` (`build_system`), `kiln/world.py` (a
`world_block` composer), `engine.py` (`run()` per-turn composition), and `config.py`.

**What needs to be done:**
- `world_block(now, location, history, n) -> str` (in `world.py`): combines `world_now(...)` under
  `## Зараз` and `recent_timed(...)` under `## Останні повідомлення`; `""` when both are empty.
- Extend `build_system(canon, memory, facts="", world="")`: append the `world` block (already
  carrying its own headers) **separate** from canon / memory / facts; empty `world` reproduces the
  v0.7 output byte-for-byte (back-compatible). *(Seam: `build_system` signature → ARCHITECTURE +
  contract test.)*
- `run()`: build the **static base** (canon + memory + facts) once; then **per turn**, compose
  `world_block(now, USER_LOCATION, history, RECENT_MESSAGES)` and pass the fresh `system` to the
  brain — so the clock advances and the timeline updates within a session. Gate on `WORLD_AWARENESS`
  (master on/off; off → `world=""`).
- Config: `WORLD_AWARENESS` (on by default, `.env`-overridable). **Pre-seed `.env` with
  `USER_LOCATION=Львів`** (from the stored location fact) so it works out of the box; the code default
  stays empty.

**Dependencies:** KILN-031 (world_now), KILN-033 (timed block).

**Expected result:**
Every turn's system prompt carries a live `## Зараз` + `## Останні повідомлення` block; `WORLD_AWARENESS`
toggles it; `world=""` is v0.7-equivalent.

**Acceptance criteria:**
- [ ] **Contract test:** `build_system(canon, memory, facts, world)` appends the `world` block,
  separate from canon / memory / facts; `world=""` is v0.7 byte-for-byte. Pinned in
  `spec/ARCHITECTURE.md`.
- [ ] **Integration test:** a `run()` turn hands the brain a `system` containing `## Зараз` and (once
  there are turns) `## Останні повідомлення`; `WORLD_AWARENESS=0` → neither — **mock brain**, fixed
  clock, zero paid calls.
- [ ] `WORLD_AWARENESS` `.env`-overridable; `.env` ships `USER_LOCATION=Львів`.
- [ ] Ties to the phase DoD: the system prompt carries the live world-now + timed-messages sections.

## v0.8 scope notes

**Total effort:** ~M (9–14 days): KILN-031 M, KILN-032 M, KILN-033 S, KILN-034 M.
**Critical path:** KILN-032 → KILN-033 → KILN-034 (KILN-031 runs in parallel from the gate).
**Phase DoD (ROADMAP §0.8):** every new session's system prompt carries a `## Зараз` section
(date / weekday / time / time-of-day / season + location, a short Ukrainian paragraph with a rhythm
cue) **and** a `## Останні повідомлення` section with the last `RECENT_MESSAGES` turns each precisely
timestamped; turns are stamped with `at`; it's deterministic given an injected clock;
`WORLD_AWARENESS` / `RECENT_MESSAGES` toggle and size it; no external calls in the core.
**Contracts pinned this phase:** the **turn shape** gains `at` (`{role, text, at}`) — KILN-032; the
**system-prompt composition** gains `world` via `build_system(canon, memory, facts, world)` —
KILN-034. Each lands its ARCHITECTURE update + contract test in the same issue.
**Design note (deviation from the ROADMAP "stretch"):** the world block is composed **per turn**, not
once at session start — the timed-messages block is empty at start and only fills as the conversation
proceeds, so a live (per-turn) rebuild is required for that feature, not optional.
**Model note:** no model is involved in the world block — it's pure local formatting. All tests run
on fixtures + a mock brain with an injected clock; **zero paid calls**.
