### KILN-052: AgentRuntime + AgentHost
**Status:** completed · **Commit:** f7fb968
`AgentRuntime` runs `engine.run()` on a daemon thread over the agent's `BroadcastHub` + `AgentPaths`
(submit/subscribe/latest_status/stop/join); `AgentHost` is the `agent_id → AgentRuntime` registry.
App lifespan boots the host (guarded by `KILN_SERVE`). `engine.run(stop_event=…)` — cooperative
cancel so a hosted agent shuts down cleanly (the `finally` still persists).
**Validation:** [x] integration (ticks with no client → 3 status events) · [x] unit (blocking brain leaves `/health` responsive) · [x] dry-run · [x] ruff · [x] acceptance
