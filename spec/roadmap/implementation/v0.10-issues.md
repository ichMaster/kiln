# v0.10 — GitHub Issues

Issues for phase **v0.10 — Inner thoughts (internal monologue)** (version **v0 — Prototype & TUI**),
derived from the per-phase Tasks in [ROADMAP.md](../../ROADMAP.md) (§0.10) and the contracts in
[ARCHITECTURE.md](../../ARCHITECTURE.md) (§Contracts — Store, Output seam, Canon/system-prompt;
§Needs and self-triggers). This file is scoped to a single phase; IDs continue from the previous
phase (KILN-038 → **KILN-039…044**).

v0.10 gives Agnika an **inner monologue**: a new `reflection` need («незібраність» — the felt
pressure, high = thoughts scattered) that, on crossing its threshold, makes her **think a private
thought** via Haiku. Thoughts are hidden by default, saved to `.kiln/store.json`, and the last N
(cross-session) ride in a `## Думки` system-prompt section; generating one **satiates** the need.
**~1 in M** a thought surfaces in the chat (marked «думка:») and becomes a real turn; `/thoughts`
shows them. Builds on 0.9 (the thought prompt sees her `## Настрій`; the new need is registered in
`state/mood.json` so it shows there too). Cheap-first (Haiku + cooldown), local, mock-tested.

## v0.10 — Inner thoughts (internal monologue)

### KILN-039 — Store: `thoughts` persistence (`.kiln/store.json`)

**Description:**
The persistence foundation for thoughts. `.kiln/store.json` gains a **`thoughts`** key alongside
`sessions` / `messages` / `summaries` / `facts`. Touches `kiln/store.py` and the store contract in
`spec/ARCHITECTURE.md`.

**What needs to be done:**
- Add a **`thoughts`** array to the store: each `{id, text, at, session, shown}` (`shown` = was it
  surfaced in the chat). `empty_store()` seeds `"thoughts": []`; `migrate_legacy` / the missing-section
  healing add the key to old stores.
- `add_thought(store, text, session, *, shown=False) -> dict` appends a thought (stable id, `at`
  stamp passed in for determinism) and returns it; atomic write + `.bak` as the rest of the store.
- **ARCHITECTURE:** extend the Store contract (`§Contracts — Store`) with the `thoughts` key.

**Dependencies:** None (gate).

**Expected result:**
`add_thought` appends a `{id, text, at, session, shown}` record; the store round-trips it; old stores
heal the `thoughts` key on load.

**Acceptance criteria:**
- [ ] **Contract test:** the store shape carries `thoughts: [{id, text, at, session, shown}]`;
  `empty_store()` includes it; a store missing the key heals on load. **ARCHITECTURE updated same commit.**
- [ ] **Unit test:** `add_thought` appends + round-trips through `save_store` / `load_store` (atomic +
  `.bak`); `migrate_legacy` adds `thoughts` to a legacy store. **No paid calls.**
- [ ] Ties to the phase DoD: thoughts are **saved to `.kiln/store.json`**.

### KILN-040 — Reflection need + thought trigger + satiation

**Description:**
The new `reflection` need and how it fires and discharges. Touches `kiln/config.py` (`DRIFT`,
`NEED_TRIGGERS`, `SATIATION`) and `kiln/engine.py` (`select_thought_trigger`).

**What needs to be done:**
- Add a `reflection` need to `DRIFT` (slow upward drift) and `NEED_TRIGGERS` (`threshold`,
  `action: "thought"`). Seed it in `state/needs.json`.
- `select_thought_trigger(state, tg)` — parallel to `select_self_trigger`, fires `reflection` on an
  **upward crossing** with the same **hysteresis + cooldown** via the `TriggerBook` (`THOUGHT_COOLDOWN`).
- Add a **`thought`** event to `SATIATION` that discharges `reflection` (the need that drove it).
  *(Seam: the `apply_satiation` event set — contract test.)*
- The loop-priority wiring (`user > reach-out > thought > idle`) and calling generation on the
  trigger land in **KILN-042** (the consumer) — here it's just the selector + the need + its discharge.

**Dependencies:** None (gate).

**Expected result:**
`reflection` drifts up and `select_thought_trigger` returns it on a crossing (then re-arms / cools
down); `apply_satiation(state, "thought")` lowers `reflection`.

**Acceptance criteria:**
- [ ] **Unit test:** `select_thought_trigger` fires once on an upward crossing, re-arms below
  threshold, and respects `THOUGHT_COOLDOWN` (mirrors the `select_self_trigger` tests).
- [ ] **Contract test:** `apply_satiation(state, "thought")` discharges `reflection` (the `SATIATION`
  event set gains `thought`).
- [ ] **Unit test:** `reflection` drift advances the need; it's in `state/needs.json`. **Mock brain.**
- [ ] Ties to the phase DoD: a `reflection` need drifts and, on crossing, is ready to fire a thought.

### KILN-042 — Thought generation (Haiku) + loop wiring (hidden)

**Description:**
On a `reflection` crossing, generate a short internal thought via the chat brain (Haiku), store it,
and discharge the need — all **hidden** for now (surfacing is KILN-043). Touches `kiln/engine.py`
(loop priority + the thought path), `state/prompts.md` (a `[thought]` prompt), `kiln/config.py`.

**What needs to be done:**
- Loop priority in `run()`: **user input > reach-out (connection) > thought (reflection) > idle** — a
  thought fires only on an input-free, non-resting tick (via `select_thought_trigger`).
- Generate the thought through `brain.chat` (Haiku/SDK, `THOUGHT_MODEL` = `CHAT_MODEL`) from a
  `[thought]` reflection prompt (`state/prompts.md`, Ukrainian) with the full system prompt
  (canon + memory + facts + world + **mood**). The result is **not** a conversation turn — it goes to
  `add_thought` (KILN-039), and `apply_satiation(state, "thought")` discharges `reflection`. Token
  usage logged like chat; **cooldown-capped** (`THOUGHT_COOLDOWN`).
- Config: `THOUGHTS_ENABLED` (master on/off), `THOUGHT_COOLDOWN`, `THOUGHT_MODEL` — `.env`-overridable.

**Dependencies:** KILN-039 (the store `thoughts` key), KILN-040 (the need + trigger + satiation).

**Expected result:**
On a reflection crossing (input-free tick), a thought is generated, stored (not shown), and the need
discharges.

**Acceptance criteria:**
- [ ] **Integration test:** a reflection crossing on an idle tick generates a thought (mock brain),
  calls `add_thought` (it lands in the store), discharges `reflection`, and **does not** display it or
  append a conversation turn.
- [ ] **Unit test:** loop priority — user input and a connection reach-out both pre-empt a thought; a
  thought never fires while resting; the cooldown gates repeats. **Mock brain, zero paid calls.**
- [ ] `THOUGHTS_ENABLED=0` → no thoughts at all.
- [ ] Ties to the phase DoD: on crossing she **thinks** via Haiku; the thought is hidden by default,
  satiates the need, and is saved to the store.

### KILN-043 — Random visibility → a real turn (Output `is_thought` seam)

**Description:**
Sometimes let a freshly generated thought surface in the chat as a marked, dim turn she remembers.
Touches the Output seam (`kiln/output.py` + `tui/output.py` + the bridge), `kiln/engine.py`,
`kiln/config.py`, and `spec/ARCHITECTURE.md`.

**What needs to be done:**
- With probability ~`1/THOUGHT_VISIBLE_EVERY` (M), using a **seedable RNG** (deterministic in tests),
  a freshly generated thought is **shown**: marked via the Output seam (`agent(..., is_thought=True)`,
  rendered dim / «думка:») **and** appended to `history` as an assistant turn (she remembers it);
  `add_thought` records `shown=True`. Otherwise it stays internal (KILN-042 behaviour).
- **ARCHITECTURE:** extend the Output seam contract — `agent(text, is_self, lead, is_thought)`; the
  bridge render event carries `is_thought`.
- Config: `THOUGHT_VISIBLE_EVERY` (M) — `.env`-overridable.

**Dependencies:** KILN-042 (thought generation).

**Expected result:**
~1/M thoughts appear in the chat marked «думка:» and enter the conversation as a turn; the rest stay
hidden.

**Acceptance criteria:**
- [ ] **Contract test:** the Output seam `agent` event gains `is_thought` (ConsoleOutput / TuiOutput /
  RecordingOutput all accept it; the bridge event carries it). **ARCHITECTURE updated same commit.**
- [ ] **Integration test:** with the RNG seeded to **hit** 1/M, a generated thought is shown
  (`is_thought=True`) **and** appended as a history turn (and stored `shown=True`); seeded to **miss**,
  it stays hidden (no turn, no display). **Mock brain.**
- [ ] Ties to the phase DoD: **~1/M** a thought **surfaces in chat** (marked) **and becomes a real turn**.

### KILN-044 — `## Думки` prompt section + `/thoughts` command

**Description:**
Carry her inner life forward and let the operator inspect it. The last N (cross-session) thoughts ride
in a `## Думки` system-prompt section, and `/thoughts` lists them. Touches `kiln/memory.py`
(`build_system` + a thoughts loader), `kiln/engine.py` (`_system`), `kiln/commands.py`, `kiln/config.py`,
and `spec/ARCHITECTURE.md`.

**What needs to be done:**
- A loader for the **last `THOUGHTS_IN_PROMPT` (N)** thoughts from the store (cross-session, like the
  facts digest); composed into a **`## Думки`** section in the system prompt, **separate** from
  canon / memory / facts / world / mood. A thought that became a turn (KILN-043) is **de-duped** out of
  `## Думки` (already in history). Composed per turn in `_system()` (newly formed thoughts appear live).
- **ARCHITECTURE:** extend the Canon/system-prompt contract — `build_system(..., thoughts)` (the
  `## Думки` layer); empty → back-compatible.
- `/thoughts` command — show the recent thoughts (store + current session) with timestamps and a
  marker for the surfaced ones, through the Output seam (`notice`), like `/usage`. Add to `COMMANDS`.
- Config: `THOUGHTS_IN_PROMPT` (N) — `.env`-overridable.

**Dependencies:** KILN-039 (store thoughts), KILN-042 (thoughts generated).

**Expected result:**
Each turn's system prompt carries a `## Думки` section with the last N cross-session thoughts;
`/thoughts` lists them.

**Acceptance criteria:**
- [ ] **Contract test:** `build_system` places `## Думки` separate from the rest; empty thoughts →
  back-compatible (byte-for-byte the prior output). **ARCHITECTURE updated same commit.**
- [ ] **Unit test:** the loader caps to the last N cross-session thoughts and de-dups any that became
  turns; `/thoughts` lists recent thoughts (with the surfaced marker) via `notice`. **Mock brain.**
- [ ] Ties to the phase DoD: a `## Думки` section carries the **last N cross-session** thoughts;
  `/thoughts` shows them.
