# v0.9 — GitHub Issues

Issues for phase **v0.9 — Mood & biorhythm** (version **v0 — Prototype & TUI**), derived from the
per-phase Tasks in [ROADMAP.md](../../ROADMAP.md) (§0.9) and the contracts in
[ARCHITECTURE.md](../../ARCHITECTURE.md) (§Contracts — Canon/system-prompt, §Needs and self-triggers).
This file is scoped to a single phase; IDs continue from the previous phase
(KILN-034 → **KILN-035…038**).

v0.9 gives Agnika a **felt inner state** surfaced in the system prompt of every message: a per-turn
`## Настрій` section listing every need with its level (`0..1`) and a short Ukrainian "big/small for
her" band, plus a per-day **biorhythm** (physical / emotional / intellectual) computed **once at
session start** from her **canon birthday** (`12.08.2001, 17:10`) and static for the session. It
extends the same per-turn system-prompt seam as v0.8's world block (`build_system` gains a `mood`
layer). No emotion label is computed — she reads the raw levels + biorhythm and decides her own tone.
All **local** and **deterministic** (injected clock + birth) — no model/external calls.

## v0.9 — Mood & biorhythm

### KILN-035 — Biorhythm builder (`kiln/mood.py`)

**Description:**
A pure, deterministic biorhythm calculator — the three classic sine cycles (physical 23 / emotional
28 / intellectual 33 days) from a birth datetime to "now", each `−1..+1` — plus Ukrainian band labels
and a short renderer. New module `kiln/mood.py`. Takes injected `now` / `birth` so it's fully
testable; in the engine it's computed **once at session start** (KILN-037).

**What needs to be done:**
- `biorhythm(now, birth) -> {"physical": float, "emotional": float, "intellectual": float}` in
  `kiln/mood.py`: `sin(2π · days_between(birth, now) / period)` for periods **23 / 28 / 33**; each in
  `−1..+1`. Pure — `now` / `birth` are `datetime`s passed in (never `datetime.now()` inside).
- `bio_band(v) -> str` — Ukrainian band: **підйом** (high positive) / **спад** (low negative) /
  **критичний день** (near a zero-crossing, `|v|` small) / **нейтрально**.
- `biorhythm_block(bio) -> str` — a short Ukrainian rendering of the three cycles with their bands +
  a one-line tone cue (the day's "weather"). Persona-layer Ukrainian.
- Period constants live in `kiln/mood.py`.

**Dependencies:** None (gate).

**Expected result:**
`biorhythm(fixed_now, fixed_birth)` returns the three `−1..+1` values; `biorhythm_block` renders them
in Ukrainian with bands and a one-line tone cue.

**Acceptance criteria:**
- [ ] **Unit test:** `biorhythm` matches a hand-computed sine value for a fixture `(now, birth)` and a
  zero-crossing **critical day**; every value stays within `−1..+1`. Pure, **mock brain / no paid call**.
- [ ] **Unit test:** `bio_band` maps high / low / near-zero to підйом / спад / критичний день.
- [ ] `biorhythm_block` produces short Ukrainian text (three cycles + bands + a one-line tone cue).
- [ ] Ties to the phase DoD: the per-day biorhythm (physical / emotional / intellectual) is computed
  deterministically from an injected clock + birth.

### KILN-036 — Mood-from-needs builder + need labels (`kiln/mood.py`)

**Description:**
The `## Настрій` section builder — each need (connection / novelty / rest / intensity) by its
Ukrainian label, level number, and a "big/small for her" band, plus the biorhythm sub-block (from
KILN-035). Pure and deterministic. Adds the Ukrainian need labels (persona layer). No emotion label is
computed — she reads the levels and decides her own tone.

**What needs to be done:**
- `need_band(value) -> str` in `kiln/mood.py`: maps `0..1` to a Ukrainian band — **низька / помірна /
  висока / дуже висока** ("how big this need is for her right now").
- `mood_block(needs, bio) -> str`: renders the `## Настрій` section — each need as
  `<label> <level> — <band>` (`близькість 0.72 — висока`, `новизна 0.30 — низька`,
  `втома 0.55 — помірна`, `напруга 0.41 — помірна`) followed by the biorhythm sub-block via
  `biorhythm_block(bio)`. Pure, no I/O — a fixed `needs` dict renders deterministically.
- **Need labels** (persona layer): `connection→близькість`, `novelty→новизна`, `rest→втома`,
  `intensity→напруга` — in config or `kiln/mood.py`. Note `rest` = fatigue (high = tired).

**Dependencies:** KILN-035 (embeds `biorhythm_block` as the sub-block).

**Expected result:**
`mood_block(needs, bio)` returns the `## Настрій` section with all four needs (label + level + band)
and the biorhythm sub-block.

**Acceptance criteria:**
- [ ] **Unit test:** `need_band` boundaries (низька / помірна / висока / дуже висока).
- [ ] **Unit test:** `mood_block` renders all four needs with the right Ukrainian labels + bands and
  includes the biorhythm sub-block. Deterministic (a fixed `needs` dict + `bio`), **mock brain**.
- [ ] Need labels read from config / `mood.py` (persona-layer Ukrainian).
- [ ] Ties to the phase DoD: the `## Настрій` section lists **all needs** (level + a big/small band).

### KILN-037 — Birthday from the canon + session biorhythm (`load_birth`)

**Description:**
Read Agnika's birth datetime from `state/canon.md` (the natal `Народження: 12.08.2001, 17:10` line),
with an `.env` override and a safe default; compute the session biorhythm **once** at `run()` start
and hold it static for the session. Touches `kiln/memory.py` (or config) for `load_birth`,
`kiln/config.py` for `AGENT_BIRTH`, and `kiln/engine.py` for the wiring.

**What needs to be done:**
- `load_birth(canon) -> datetime`: parse the birth date/time from the canon text (the natal line,
  e.g. `Народження: 12.08.2001, 17:10, Львів`), tolerant of small format variations; fall back to a
  safe default when the line is absent / unparseable (start must never crash).
- Config: `AGENT_BIRTH` (`.env`-overridable, `DD.MM.YYYY[ HH:MM]`) overrides the parsed value.
- `run()` computes `session_bio = biorhythm(_now(), birth)` **once** at start and passes that static
  value into `_system()` each turn (the biorhythm doesn't change mid-session).

**Dependencies:** KILN-035 (biorhythm).

**Expected result:**
At session start the biorhythm is computed once from the canon birthday (or `AGENT_BIRTH`) and stays
fixed for the whole session.

**Acceptance criteria:**
- [ ] **Unit test:** `load_birth` parses the canon natal line into the right `datetime`; falls back on
  a missing / garbled line; `AGENT_BIRTH` overrides the parsed value. **Mock brain / no paid call**.
- [ ] **Integration:** the session biorhythm is computed **once** at `run()` start (not per turn) — the
  same value across the session (injected clock, mock brain).
- [ ] Ties to the phase DoD: the biorhythm is computed once at session start from the canon birthday,
  static for the session.

### KILN-038 — Mood → system prompt (per-turn) — `build_system` seam

**Description:**
Wire the mood into the system prompt. Extend `build_system` with a `mood=""` layer (the `## Настрій`
block), separate from canon / memory / facts / world; `_system()` composes it **per turn** (needs are
live, the biorhythm is static); gate with `MOOD_AWARENESS` (+ `BIORHYTHM`). **Seam:** the
`build_system` signature changes → ARCHITECTURE update + a contract test **in the same issue**. Touches
`kiln/memory.py` (`build_system`), `kiln/engine.py` (`_system`), `kiln/config.py`.

**What needs to be done:**
- Extend `build_system(canon, memory, facts="", world="", mood="") -> str` — append the `## Настрій`
  block when `mood` is non-empty; empty `mood` → the v0.8 output (back-compatible).
- `_system()` composes `mood = mood_block(state.needs, session_bio)` **per turn** (needs drift every
  tick; the biorhythm is the session-static value from KILN-037) when `MOOD_AWARENESS`; off → no
  section. `BIORHYTHM` off → omit the biorhythm sub-block.
- Config: `MOOD_AWARENESS` (master on/off, like `WORLD_AWARENESS`) and `BIORHYTHM` (on/off) —
  `.env`-overridable.
- **ARCHITECTURE:** update the Canon/system-prompt contract to
  `build_system(canon, memory, facts, world, mood)` and document the `## Настрій` block (needs +
  biorhythm, composed per turn).

**Dependencies:** KILN-036 (`mood_block`), KILN-037 (the session biorhythm).

**Expected result:**
Every turn's system prompt carries a `## Настрій` section (needs + biorhythm), composed per turn;
`MOOD_AWARENESS` toggles it; `mood=""` reproduces the v0.8 output exactly.

**Acceptance criteria:**
- [ ] **Contract test:** `build_system` places `## Настрій` **separate** from canon / memory / facts /
  world; `mood=""` is byte-for-byte v0.8-equivalent. **ARCHITECTURE updated in the same commit.**
- [ ] **Integration test:** `_system()` composes the mood per turn — a re-compose after needs drift
  reflects the **changed** needs while the biorhythm stays fixed (injected clock, **mock brain**).
- [ ] `MOOD_AWARENESS` off → no `## Настрій`; `BIORHYTHM` off → no biorhythm sub-block.
- [ ] Ties to the phase DoD: every message carries a `## Настрій` section (all needs + the day's
  biorhythm), composed per turn, deterministic, local-only.
