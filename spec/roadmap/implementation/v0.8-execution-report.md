## Design note

Per the issues file, the world block is composed **per turn** (not once at session start): the
timed-messages timeline is empty at start and fills as the conversation proceeds, so a live rebuild
is required for that feature. `run()` keeps the static canon+memory+facts base and only re-composes
the cheap world string each turn. `TIMEZONE` is honoured (`zoneinfo`) when set, else the local clock.
