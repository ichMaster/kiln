# kiln

Simplified chat with Claude as the brain — state-aware Haiku/Opus routing.

Чат-двіжок із «потребами»: він живе циклом коротких тіків, сам інколи озивається
першим, а на змістовні ходи кличе сильнішу модель. Дешева розмова йде через
Haiku, складніша — через Claude (Opus). Персона співрозмовниці налаштовується
файлом, моделі й поведінка — через `.env`.

> Як це влаштовано всередині — у [`docs/`](docs/)
> ([архітектура](docs/architecture.md), [як працює](docs/how-it-works.md)).

## Встановлення

Потрібен Python 3.10+. Перший раз — створи віртуальне середовище й постав
пакет (залежність `anthropic` потрібна лише живій гілці чату; dry-run іде на
самій стандартній бібліотеці):

    python3 -m venv .venv
    source .venv/bin/activate          # Windows: .venv\Scripts\activate
    pip install -e .                   # або `pip install -e .[dev]` для тестів/лінту

Далі досить тримати `.venv` активованим у кожній новій сесії терміналу.

## Запуск

**Dry-run** — детермінований демо-сценарій, без жодних викликів моделі:

    kiln                # або: python -m kiln

**Наживо** — інтерактивно: тіки крутяться самі, ти пишеш у термінал,
повідомлення підхоплюються на найближчому тіку:

    KILN_LIVE=1 kiln    # або: KILN_LIVE=1 python -m kiln

Живий режим має дві вимоги (за гілками):

- **Чат (Haiku)** — ключ `ANTHROPIC_API_KEY` у `.env` або в середовищі.
- **Роздум / тули (Opus)** — установлений і залогінений **Claude Code CLI**
  (`claude`), бо ця гілка викликає `claude -p`.

`KILN_LIVE=1` можна також задати в `.env`, щоб не писати щоразу.

## Налаштування

Локальний файл `.env` (не комітиться) задає моделі й поведінку — без правки
коду. Справжні змінні середовища мають пріоритет над файлом.

| Змінна | Що задає | Дефолт |
|---|---|---|
| `CHAT_MODEL` | модель гілки чату | `claude-haiku-4-5-20251001` |
| `DEEP_MODEL` | модель гілки роздумів | `claude-opus-4-8` |
| `TICK_SECONDS` | довжина тіку (сек; діє лише наживо) | `0.5` |
| `THINK_THRESHOLD` | наскільки легко хід іде у сильнішу модель | `0.45` |
| `SELF_COOLDOWN` | пауза (тіків), перш ніж двіжок озветься знову | `5` |
| `KILN_LIVE` | `1` — увімкнути живий режим | — |
| `ANTHROPIC_API_KEY` | ключ для гілки чату | — |

**Персона.** Голос і характер співрозмовниці лежать у
[`state/canon.md`](state/canon.md) — це звичайний текст, редагуй вільно. Якщо
файлу немає, береться вбудований запасний канон.

## Спілкування

Просто пиши у термінал. Двіжок відповідає сам і **може озватися першим**, коли
його внутрішня «потреба» накопичилась.

Рядки, що починаються з `/`, — це команди (вони не йдуть у модель):

| Команда | Дія |
|---|---|
| `/status` | скільки ходів, найгарячіша потреба, режим |
| `/needs` | поточні рівні потреб |
| `/memory` | вміст довгої пам'яті |
| `/history` | останні ходи цієї сесії |
| `/ask <текст>` | примусово запитати Claude (сильніша модель) |
| `/clear` | очистити історію сесії |
| `/help` | список команд |
| `/quit` | вихід |

## Де що зберігається

- `state/` — потреби, персона (`canon.md`), промпти, довга пам'ять.
- `history/` — повний транскрипт кожної сесії у JSON (зберігається на виході;
  локальний, не комітиться). Зручно для подальшого RAG.

На виході (зокрема через `/quit` чи Ctrl-C) розмова підсумовується в довгу
пам'ять, а сирий транскрипт лягає у `history/` — наступного запуску двіжок
«пам'ятає» попередні розмови.
