kiln — Release Notes
====================

Version 0.8.1 (2026-06-28)
---------------------------
- Named speaker labels (USER_NAME / AGENT_NAME) in transcripts and the prior-session timeline, instead of user/assistant role keywords
- Date+time stamps in the prompt: every line of the prior-session timeline, plus the user's own messages in the live conversation — Agnika's replies stay clean (fixes her echoing/duplicating timestamps in replies)
- Self-trigger reach-out reworked: [connection] prompts are now internal impulses (she initiates, not "answering" a fake user question), plus an anti-repeat silence note when she reaches out again with no reply since
- prompts.md cleanup: dropped the unused [novelty]/[rest]/[intensity] sections and put the header comment in English

Version 0.8.0 (2026-06-28)
---------------------------
- World & temporal awareness: Agnika now knows the time, place, and conversation tempo
- `## Зараз` world-now section in the system prompt: weekday/date, time-of-day, season, location, and a rhythm cue (KILN-031)
- Every turn carries a precise ISO timestamp ({role, text, at}) (KILN-032)
- `## Повідомлення з минулої сесії` section: the previous session's last N turns, each timestamped (KILN-033)
- build_system gains the world block, composed per turn so the clock stays live; gated by WORLD_AWARENESS (KILN-034)
- New .env knobs: USER_LOCATION (pre-seeded Львів), TIMEZONE, RECENT_MESSAGES, WORLD_AWARENESS
- Local-only (no external calls); weather/calendar/news deferred to a later tool-backed layer
- Needs calibration tuning: novelty drifts slower, replies tire less

- Report enriched: per-model stats per session + claude -p execution count
- Marks v0 (Prototype & TUI) feature-complete

Version 0.6.0 (2026-06-28)

Version 0.5.1 (2026-06-27)
---------------------------
- Add /prompt command — shows the system prompt (canon + memory) + the messages array sent to the model
- Notices (system messages + slash-command output) now render grey in both console and TUI

Version 0.5.0 (2026-06-27)
---------------------------
- Short memory: a single .kiln/store.json holds all session state (sessions / messages / summaries), with atomic write + .bak recovery (KILN-017)
- Session close prunes noise, then writes the transcript + one summary to the store (KILN-018/019)
- Legacy state/memory.md + history/*.json migrated in idempotently (lossless, collision-safe) and retired (KILN-021)
- Stored summaries load into every new session's system prompt (KILN-020)
- Session summaries now run on Haiku (Messages API) — ~2x faster than Opus, cost-guarded
- TUI quit waits for the summary ("saving session…") instead of killing it after 2s
- Removed the now-redundant /memory and /history commands

Version 0.4.2 (2026-06-27)
---------------------------
- Reach-out model: only connection self-triggers; intensity/novelty choose the brain (deep / session-wiki / chat) for both self-messages and user turns
- /self command toggles proactive self-messages; status bar shows self:on/off
- Rest gate: too tired -> stops answering, says "мені треба відпочити" once, wakes at REST_WAKE
- session-wiki reach-out via `claude -p --agent`; per-agent satiation that drops novelty
- Opus is never called via the API key: chat (SDK) refuses Opus; every `claude -p` call runs with ANTHROPIC_API_KEY stripped (subscription); fixed the variadic --allowedTools/stdin bug (deep + tool)
- Extended thinking ON for every `claude -p` call (deep / tool / summarize); session summaries on Opus
- Roadmap: added 0.6 (short memory — .kiln/store.json) and 0.7 (long memory — user facts)
- Needs recalibration; test suite 107 -> 136 (mock brain, zero paid calls)

Version 0.1.0 (2026-06-25)
---------------------------
- Needs-driven chat engine: a loop of cheap local ticks; the LLM "brain" fires only on user input or a need crossing its threshold
- Two-brain routing — Haiku chat branch (Anthropic SDK) vs Opus deep branch (claude -p), chosen by message markers + need-state weight
- Needs model with drift/satiation cycle; self-triggers with hysteresis + cooldown; slash commands intercepted before routing
- Input channels (scripted dry-run + live stdin); cross-session memory summaries; raw session transcripts for RAG
- Modular split (config/history/usage/memory/commands/engine), JSON-seeded needs, Agnika persona, TUI output
- .env config, external canon file, venv setup, CLAUDE.md + docs/
