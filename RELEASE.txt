kiln — Release Notes
====================

Version 0.4.2 (2026-06-27)
---------------------------
- Reach-out model: only connection self-triggers; intensity/novelty choose the brain (deep / session-wiki / chat) for both self-messages and user turns
- /self command toggles proactive self-messages; status bar shows self:on/off
- Rest gate: too tired -> stops answering, says "мені треба відпочити" once, wakes at REST_WAKE
- session-wiki reach-out via `claude -p --agent`; per-agent satiation that drops novelty
- Opus is never called via the API key: chat (SDK) refuses Opus; every `claude -p` call runs with ANTHROPIC_API_KEY stripped (subscription); fixed the variadic --allowedTools/stdin bug (deep + tool)
- Extended thinking ON for every `claude -p` call (deep / tool / summarize); session summaries on Opus
- Roadmap: added 0.6 (short memory — .kiln/store.json) and 0.7 (long memory — user facts)
- Needs recalibration; test suite 107 -> 136 (mock brain, zero paid calls)

Version 0.4.1 (2026-06-25)
---------------------------
- Lumi-style top bar: standard Textual Header + two status/stats lines
- 3-line bordered input box ("You", Enter sends / Shift+Enter newlines), with right-border and spacing fixes
- Needs panel in its own bordered box: per-tick counter, bars colored by closeness to threshold (green->yellow->red), widened to 50 steps, and each need's NEED_TRIGGERS action (-> chat/deep/idle)
- Chat replies: model shown as a dark-green (model) tag, bold names, white reply body on the line after the name; removed the per-turn token/latency line (now only in the status bar)
- Fixed a teardown crash in the TUI drain timer (NoMatches on exit) - also de-flaked the Textual pilot tests

Version 0.4.0 (2026-06-25)
---------------------------
- Lumi-like TUI: a live two-line status bar (status, model, hottest need; last/total tokens + latency) and a needs/thresholds panel replacing Lumi's reasoning box (KILN-013/014)
- Per-tick status event (needs + thresholds + session stats) on the Output/bridge seam, plus a SessionStats accumulator (KILN-012)
- Chat-log polish: per-turn `· model · in→out tok (total) · {latency}s` line; self-trigger replies marked (KILN-015)
- Command hints + keybinding footer scoped to implemented features only; copy reply / copy all / clear (Ctrl+Y/O/L) (KILN-016)
- i18n: code comments, docstrings, docs, and operator-facing UI strings are now English; the Ukrainian persona/conversation layer stays Ukrainian
- Test suite 80 -> 107 (all on a mock brain); CI green on Python 3.10/3.12

Version 0.3.0 (2026-06-25)
---------------------------
- Terminal UI client (Textual): scrollable reply log + fixed input line; launch with `kiln --tui` (new `tui` extra) (KILN-011)
- Echo-free bridge bus (tui/bridge.py) decoupling the tick loop from the UI thread — the engine keeps ticking and self-triggering in the background while the UI renders (KILN-007/011)
- TuiOutput / TuiChannel adapters plug the Textual client into the v0.2 Output/Channel seams — engine core unchanged (KILN-008/009)
- Slash-command output now flows through the Output seam (no more direct print), so every client captures it (KILN-010)
- Test suite 55 -> 80 (all on a mock brain, zero paid calls); CI installs the tui extra

Version 0.2.0 (2026-06-25)
---------------------------
- Restructured into an installable kiln/ package with a `kiln` console entry and pyproject.toml (dynamic version from VERSION); dropped requirements.txt (KILN-001)
- Brain seam — both brains behind a mockable Brain interface (LiveBrain/MockBrain); the core no longer touches the SDK/CLI directly (KILN-002)
- Output seam — the engine writes replies through an Output port instead of print, readying the v0.3 TUI bus (KILN-006)
- Test suite — 55 pytest tests (unit + contract + integration) running entirely on a mock brain; zero paid calls (KILN-003)
- Tooling — ruff lint+format config and an advisory mypy stub; codebase formatted clean (KILN-004)
- CI — GitHub Actions runs ruff + pytest on push/PR across Python 3.10/3.12, no API key (KILN-005)

Version 0.1.0 (2026-06-25)
---------------------------
- Needs-driven chat engine: a loop of cheap local ticks; the LLM "brain" fires only on user input or a need crossing its threshold
- Two-brain routing — Haiku chat branch (Anthropic SDK) vs Opus deep branch (claude -p), chosen by message markers + need-state weight
- Needs model with drift/satiation cycle; self-triggers with hysteresis + cooldown; slash commands intercepted before routing
- Input channels (scripted dry-run + live stdin); cross-session memory summaries; raw session transcripts for RAG
- Modular split (config/history/usage/memory/commands/engine), JSON-seeded needs, Agnika persona, TUI output
- .env config, external canon file, venv setup, CLAUDE.md + docs/
